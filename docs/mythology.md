# 命名體系與層級映射

稜鏡用北歐神話做溝通層的隱喻。神話名出現在模組目錄、命令列分組、文件與介面文案，不進入資料表、介面欄位或日誌鍵名。

| 層級或組件 | 神話名 | 系統職責 | 程式碼 |
|---|---|---|---|
| 產品 | 稜鏡（Prism Bifröst） | 整體 | `prism` |
| 探針層 | 福金與霧尼（Huginn & Muninn） | 多平台公開採集與健康度 | `prism/raven/` |
| 採集標準化 | 彩虹橋基座 | 原始條目、去重、持久化 | `prism/bridge/` |
| 融合歸併 | 彩虹橋橋身 | 提及歸併為規範事件 | `prism/weave/` |
| 研判告警 | 海姆達爾（Heimdall） | 校準、突發、優先級 | `prism/watch/` |
| 告警通道 | 加拉爾號角（Gjallarhorn） | 高優先級推送 | `prism/horn/` |
| 交付簡報 | 伊里斯（Iris） | 簡報與複核工作台 | `prism/herald/`、`prism-console/` |

介面上的視覺隱喻只做三件事：載入時的稜鏡分光、圖譜裡的白點與光譜色、健康度以橋面完整度表示降級。不使用神像、符文或紋樣。
